# Contributing

This project is intended to be open hardware and open software.

Before contributing, please read:

- `docs/SPEC-v0.1.md`;
- `docs/MODULE-STANDARD.md`;
- `docs/CAPABILITY-API.md`;
- `SECURITY.md`.

## Good first contributions

- documentation improvements;
- module naming and use cases;
- mechanical ideas;
- RF coexistence notes;
- example module descriptors;
- Android UI wireframes;
- test plans.

## Safety

Do not propose features intended for unauthorized interception, jamming, credential theft, evasion or disruption of third-party systems.
