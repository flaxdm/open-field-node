# Contributing / Участие

Проект задуман как открытое hardware и software сообщество.

Перед участием прочитай:

- `docs/ru/SPEC-v0.1.md`;
- `docs/ru/MODULE-STANDARD.md`;
- `docs/ru/CAPABILITY-API.md`;
- `SECURITY_RU.md`.

## Хорошие первые вклады

- улучшение документации;
- сценарии использования модулей;
- механические идеи;
- заметки по RF‑сосуществованию;
- примеры module descriptors;
- wireframes Android UI;
- тест‑планы.

## Безопасность

Не предлагай функции для несанкционированного перехвата, глушения, кражи учётных данных, обхода защиты или нарушения работы чужих систем.
