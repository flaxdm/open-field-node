# Open Field Node

Open modular headless field platform for communications, radio monitoring, survival scenarios and auditing your own networks.

The device has no screen and no keyboard. An Android smartphone is used for control, mission planning, live monitoring, analysis and reporting. The node itself can run autonomously, store logs and sync later.

## Scope

- field communications;
- radio listening and SDR;
- LoRa/Meshtastic;
- DMR hotspot as an optional module;
- dual Ethernet / dual Wi-Fi / LTE-SIM;
- offline survival mode;
- own-network security lab.

## Important

Security and RF transmit features are designed for your own devices, your own network or an isolated lab only.
