# Security Policy / Политика безопасности

Проект предназначен для lawful testing собственных систем, устройств и лабораторных сред.

## Разрешённый scope

- собственная сеть;
- собственные точки доступа;
- собственные клиенты;
- собственные RF‑устройства;
- изолированные lab VLAN и стенды;
- устройства с явным разрешением.

## Не разрешено

- атаки на чужие сети;
- перехват коммуникаций без авторизации;
- jamming или DoS вне контролируемой лаборатории;
- обход rolling code/access control систем, которыми ты не владеешь;
- кража учётных данных;
- stealth/persistence tooling.

## Сообщения об уязвимостях

Если нашёл security issue в репозитории, сначала свяжись с maintainer через private discussion, а потом уже публикуй.
