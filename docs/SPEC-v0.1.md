# Specification v0.1

Working name: Open Field Node

## Summary

Open modular headless platform for field communications, radio monitoring, survival and auditing of own networks. Android smartphone is the main UI. The node remains autonomous without the phone.

## Core principles

1. Open hardware and software.
2. Replaceable compute core.
3. Strong backplane-based modularity.
4. No screen and no keyboard on the device.
5. Android phone as controller, not as the only brain.
6. RF modules must coexist safely.
7. 3D-printable enclosure.
8. Community-extensible modules.

## Main functions

- autonomous field missions;
- SDR receive/monitor;
- LoRa/Meshtastic;
- optional DMR hotspot module;
- dual Ethernet;
- dual Wi-Fi;
- LTE with SIM;
- offline survival services;
- own-network security lab.

## Non-goals for v0.1

- full product certification;
- final mechanical standard;
- final RF front-end;
- final legal compliance for every region.
