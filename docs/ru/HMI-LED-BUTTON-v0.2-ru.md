# OFN Человеческий интерфейс: LED и кнопка v0.2

У устройства нет экрана. Весь интерфейс — Android-приложение по Wi-Fi плюс **один RGB-светодиод и одна кнопка** на верхней кромке панели (позиция зафиксирована в MECHANICAL-v0.2). Этот документ фиксирует их поведение, чтобы софт и схема сошлись.

## 1. Железо

- LED: один адресный RGB (WS2812B-mini или обычный RGB с 3 ножками ШИМ). Рекомендация — WS2812B-mini: одна ножка GPIO от MCP23017 не потянет ШИМ-тайминги, поэтому либо свободный GPIO CM5 напрямую, либо обычный RGB на 3 PWM-канала CM5. **Решение: обычный общий-катод RGB на 3 аппаратных PWM CM5** (GPIO12/13/19, дублирование PWM1 допустимо — LED не критичен ко времени). Ток <20 мА на канал, резисторы на плате.
- Кнопка: тактовая на верхней кромке, подтяжка к 3V3 + RC-антидребезг (100н + 10к), GPIO с прерыванием. Корпусная кнопка сбоку в v0.3 — если найдём подходящую.

## 2. Поведение светодиода

Язык — короткие вспышки на фоне состояния. «Дыхание» = плавная пульсация 1 Гц.

| Состояние узла | Цвет / паттерн |
|---|---|
| Выключен / нет питания | темно |
| Загрузка (boot → сервисы стартуют) | синее дыхание |
| Работа, всё в норме | зелёный, редкий одиночный импульс каждые 5 с («жив») |
| Точка доступа активна, нет подключённого телефона | зелёное дыхание |
| Телефон подключён по API | зелёный, короткая вспышка каждую 1 с |
| Предупреждение (просадка питания, слот перезагружен) | жёлтый, 3 вспышки, затем возврат к состоянию |
| Survival mode | жёлтое дыхание |
| Ошибка (питание вне диапазона, перегрев, core не стартует) | красный, частые вспышки 4 Гц |
| Выключение (graceful shutdown) | синий затухающий градиент 3 с → темно |
| Зарядка внешнего устройства (USB-C/A выход активен) | белый импульс раз в 3 с (добавка к основному состоянию, приоритет ниже) |

Правила: паттерн ошибки имеет высший приоритет; белый индикатор зарядки показывается только при нормальной работе.

## 3. Поведение кнопки

| Действие | Результат |
|---|---|
| Короткое нажатие (<0.5 с) | Отправка события `button.short_press` в control API; приложение решает (по умолчанию — показать статус) |
| Удержание 2 с | Toggle точки доступа (выкл/вкл) — быстрый способ «потушить радио» |
| Удержание 5 с | Graceful shutdown всех сервисов и питания ядра (soft power off) |
| Удержание 10 с | Hard power-cut всего дерева (аналог выдёргивания батареи); фиксируется флаг «некорректное выключение» в логе |

Антидребезг в железе + подтверждение 30 мс в софте. События всех удержаний логируются `ofn-logd` (для аудита: кто и когда выключал узел).

## 4. Состояние «темно»

Узел может работать «в темноте» — радиомолчание режима: LED выключен насовсем, кнопка работает. Переключается из приложения или 4 быстрых нажатия. В темноте ошибка всё равно показывается — безопасность важнее маскировки.

## 5. Для схемы носителя (KiCad)

- GPIO12 (PWM0) → R → красный анод; GPIO13 (PWM1) → зелёный; GPIO19 (PWM1) → синий; общий катод → GND. Либо, если PWM-каналы понадобятся elsewhere, мигать через бит-банг — LED не критичен.
- Кнопка: GPIO24, прерывание по фронту, RC 100н/10к на плате.
- Оба органа — на гибких выводах/шлейфе к кромке панели либо прямо на подпанели верхней кромки (решить на механике корпуса v0.3; для P1 платы — разъём 2.54 под вынос).
