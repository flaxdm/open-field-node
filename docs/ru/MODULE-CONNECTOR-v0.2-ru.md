# Сравнение разъёмов модулей v0.2

Ограничение: модули должны быть на распространённых и недорогих компонентах, без свалки всего на USB.

## Варианты разъёмов

| Вариант | Цена | Ток | Данные | Вывод |
|--------|------|-----|--------|-------|
| IDC box header 2.54 мм (2×5 / 2×8) | очень дёшево | ~1–3 А через параллельные контакты | UART, I2C, SPI, GPIO | лучший для low-speed слотов |
| JST-XH / PH на проводах | дёшево | 1–3 А | только low-speed | кабели, не основа backplane |
| Розетка M.2 (E-key / M-key) | средняя | только 3.3 В логика | PCIe, USB | хорошо для H-слота, но риск кастомной распиновки |
| Кромка PCIe x1 gold finger | дешёвая пара | питание через контакты | PCIe gen1/gen2 | лучший для одного H-слота |
| USB-C как разъём модуля | дёшево | сложности PD | один USB линк | отклонено: обманчиво и хрупко |

## Рекомендуемая двухклассовая система

### Class L — low-speed слоты (LoRa, GPS, статус, DMR control)

Ключевание: shrouded IDC box header 2.54 мм, 2×8 (16 контактов).

Предлагаемая распиновка:

| Контакты | Сигнал |
|----------|--------|
| 1–3 | +5 В (параллельно) |
| 4–6 | GND |
| 7 | I2C SDA |
| 8 | I2C SCL |
| 9 | UART TX |
| 10 | UART RX |
| 11 | SPI SCK |
| 12 | SPI MISO |
| 13 | SPI MOSI |
| 14 | CS / ID модуля |
| 15 | EN / PG |
| 16 | +3.3 В |

Рейтинг 5 В / 2 А на слот через три параллельных контакта.

### Class H — high-speed слоты

- H1: кромка PCIe x1 (gold fingers на модуле) для SDR host, NVMe или второго GbE.
- H2: USB 3.0 через внутренний штыревой разъём или кабель для одного USB3 устройства.
- Нативный GbE от CM5 заводится на backplane как основной сетевой путь.

## Правило USB бюджета

- Не более двух высокоскоростных USB-устройств.
- SDR-класс — только в H-слотах.
- LTE-модему хватает USB 2.0.
- Управляющие модули USB не используют.

## Блок-схема MVP carrier

```
                    ┌────────────────────────────┐
 12 В in ──prot────►│ buck 5В/6А      buck 3.3В │
                    └───┬─────────┬────────┬─────┘
                        │         │        │
   ┌──── ядро CM5 ──────┼─────────┼────────┼──────────────┐
   │ GbE ───────────────►│ основной RJ45               │
   │ PCIe x1 ───────────►│ H1 (SDR / NVMe / 2nd GbE)   │
   │ USB3 ──────────────►│ H2 (USB3 SDR / LTE / диск)  │
   │ USB2 ──────────────►│ LTE / отладка               │
   │ SPI, UART, I2C ────►│ Bay1 LoRa Bay2 GPS Bay3 …   │
   │ GPIO через MCP23017─►│ enable / power-good слотов  │
   └──────────────────────┴──────────────────────────────┘
```
