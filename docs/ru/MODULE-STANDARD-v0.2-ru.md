# OFN Стандарт модуля v0.2

Стандарт полевых сменных модулей (класс L) для носителя Open Field Node.

## 1. Механика

| Параметр | Значение |
|---|---|
| Размер платы модуля | 22 × 60 мм |
| Толщина | 1,6 мм FR4 (прототип), для RF-модулей допустимо 0,8–1,0 мм |
| Шаг на носителе | 25 мм (6 слотов) |
| Разъём | IDC 2×8 (16 контактов, 2,54 мм), с ключом, закрытый корпус на носителе |
| Фиксация | Плата входит в направляющие пазы 1,5 мм в стенке корпуса; трение IDC + паз = без винтов на прототипе |
| Лицевая панель | SMA (RF-модули) или окно светодиода статуса, вровень с фронтальной панелью |
| Маркировка | Название и версия на шелкографии с торца; номер слота на носителе |

Обоснование: 22×60 соответствует шагу 25 мм с перегородками 1,5 мм между слотами. IDC 2×8 дешёвый, исключает переполюсовку ключом, а закрытый корпус защищает контакты в поле. «Золотые пальцы» на прототипе не нужны — IDC паяется вручную и удобен для отладки; переход на краевой разъём — вопрос v0.3, если появится проблема износа контактов.

## 2. Электрика (распиновка класса L)

16-контактный IDC, вид на плату модуля, контакт 1 обозначен ключом/треугольником:

| Контакт | Сигнал | Примечания |
|---|---|---|
| 1–3 | BAYn_5V | 5 В от ограничителя слота, ≤2 А на слот |
| 4–6 | GND | Общая земля |
| 7 | SDA | I2C, логика 3,3 В, общая шина (подтяжки 1 кОм на носителе) |
| 8 | SCL | I2C, 3,3 В |
| 9 | TX | UART из модуля → CM5 (3,3 В) |
| 10 | RX | UART из CM5 → модуль (3,3 В) |
| 11 | SCK | SPI (общая, максимум 3 периферии) |
| 12 | MISO | SPI |
| 13 | MOSI | SPI |
| 14 | CS | Выбор кристалла, по одному на слот от MCP23017 |
| 15 | EN/PG | Enable выход / power-good вход (модуль подтягивает вверх, когда готов) |
| 16 | 3V3 | 3,3 В с носителя, ≤200 мА на слот |

Правила:
- Вся логика — 3,3 В. Не подавать 5 В на контакты 7–15.
- Модулю хватает только UART (например LoRa) — контакты SPI можно не задействовать, это нормально.
- CS и EN/PG — персональные для каждого слота, идут через расширитель MCP23017, чтобы менеджер слотов знал, что воткнуто, и мог перезагрузить зависший модуль через EN.
- I2C — общая шина: 0x50–0x57 зарезервированы под EEPROM модулей (формат HAT), остальные адреса должны быть перечислены в дескрипторе модуля.

## 3. Идентификация модуля

Два способа, решение D10:

1. **Свои модули**: EEPROM класса AT24C32 (256 Б) на I2C 0x50–0x57, формат по `MODULE-DESCRIPTOR-v0.2.md` (UUID, класс, лимиты тока, RF-регион, ASCII-имя).
2. **Готовые модули (mikroBUS Click и т.п.)**: EEPROM нет. `ofn-modmgr` определяет модуль по ручной конфигурации (слот → тип модуля) плюс опциональные подсказки от проброса I2C-адресов из реестра дескрипторов.

Коды классов: 0x01 LoRa, 0x02 GPS, 0x03 статус, 0x04 сеть, 0x05 DMR.

## 4. Чек-лист платы модуля (перед установкой в слот)

- [ ] Плата в габарите 22×60, компоненты не выше 12 мм, кроме SMA/светодиода
- [ ] Маркировка контакта 1 видна, совместимость с ключом
- [ ] Потребление 5 В не выше заявленного в дескрипторе; бросок тока ниже срабатывания ограничителя (TPS2553, 2 А)
- [ ] EEPROM прошита и читается по выбранному адресу 0x5x
- [ ] Подтяжка EN/PG присутствует (10 кОм к 3V3 на модуле)
- [ ] Гайка SMA затянута от руки; острые кромки платы не касаются коакса

## 5. Дополнительно для RF-модулей

- Зона антенны: кольцо свободное от земли ≥5 мм вокруг SMA на стороне платы.
- Для 868 МГц: битмап региона в дескрипторе; прошивка обязана запретить передачу вне заявленного региона.
- GPS-модули: посадочное место SAW-фильтра обязательно, ставить GPS в слот максимально далеко от Wi-Fi.

## 6. Открытые вопросы для v0.3

- Краевой разъём («золотые пальцы») вместо IDC: решать после теста износа на P0.
- Фиксация карты: если трения IDC мало в корпусе — добавить печатный верхний рельс.
- Модули класса H (PCIe/USB3): отдельный стандарт, здесь не описан.
