# Черновик стандарта модуля

## Классы модулей

- Core;
- Network;
- RF;
- SDR Host;
- Power;
- Storage;
- Status;
- Expansion.

## Механические требования

- модуль в формате карты с направляющими;
- 4 точки крепления;
- keying от неправильной установки;
- передняя панель под разъёмы;
- внешние SMA или иные RF‑разъёмы для RF‑модулей;
- видимая маркировка слота;
- тепловой зазор;
- поддержка 3D‑печати корпуса.

## Электрические требования

Backplane должен предоставлять:

- основной field bus 12 V;
- контролируемые линии питания;
- защита от переполюсовки;
- ограничение тока;
- USB 3.0;
- Gigabit Ethernet;
- I2C для ID и телеметрии;
- UART service;
- GPIO для кнопок/статуса.

Каждый модуль должен предоставлять descriptor и безопасное поведение по питанию.
