# RF plan v0.2 (черновик, Gate 4)

Решение по региону D13: основной диапазон 868 МГц. Вся RF-работа в проекте следует правилу безопасности: только собственные устройства / собственная сеть / изолированный лабораторный стенд.

## Диапазоны и назначение

| Функция | Диапазон | Профиль | Статус |
|---------|----------|---------|--------|
| LoRa / Meshtastic | 868 МГц | План каналов LoRaWAN RU864 (диапазон класса 864.1–865.9 МГц) | основной |
| LoRa запасной | 433 МГц | Профиль RU433 | опциональный вариант модуля |
| Wi-Fi точка управления | 2.4 ГГц | 802.11n AP на сетевом модуле (D12) | только локальный линк, малая мощность |
| SDR прослушивание | широкий RX | В MVP только приём; TX — отдельным гейтом | лабораторно |
| DMR hotspot | UHF 400–470 МГц (регионально) | пост‑MVP, нужна проверка легальности | покупка не планируется |

## Политика мощности TX (до покупки любого TX-модуля)

- 868 МГц ISM: держать TX ≤ 25 мВт ЭИИМ с дисциплиной duty cycle по региональным правилам; финальные цифры сверить с актуальными правилами RU/EU до разрешения TX в прошивке.
- Wi-Fi AP: минимально необходимая мощность, фиксированный канал, никакого выхода в интернет через него.
- Все TX-модули несут битовую карту регионов в дескрипторе; прошивка запрещает TX, если регион дескриптора ≠ настроенному региону.

## План антенн и сосуществования (уровень платы)

- Антенны LoRa 868 и Wi-Fi 2.4: разнос ≥ 5 см на лицевой панели; где возможно — разная поляризация.
- GPS (L1 1575 МГц) — в самый дальний от Wi-Fi модуля слот; GPS-тракт видит 3-ю гармонику Wi-Fi — заложить посадочное место SAW-фильтра на GPS-модуле.
- Слот SDR H1: зарезервированы 12 В aux; антенна выводится на SMA лицевой панели.
- Встроенных антенн нет: все RF-модули — через SMA/IPEX пигтейлы на панель.

## Требования RF к модулям (для спецификации модуля)

- LoRa-модуль: класс SX1276, 868 МГц, маломощный вариант (ПА ≤100 мВт, лимит в прошивке), IPEX/SMA.
- Wi-Fi модуль: 2.4 ГГц, умеет AP (ESP32-класс или USB-WiFi на H2), внешняя антенна через IPEX при экранированном корпусе.
- Все модули: гармоники/помехи по тест-плану модуля (стенд, собственное оборудование).

## Чеклист Gate 4 (до покупки RF-железа)

1. Региональные правила перепроверены (мощность TX 868 МГц, duty cycle, SRD-правила).
2. Выбран вариант LoRa-модуля (868, разъём антенны, лимит TX).
3. Выбран Wi-Fi модуль (подтверждена работа в режиме AP).
4. Эскиз разноса антенн в механическом конверте (envelope-документ).
5. Тест-план RF-модулей (лабораторный стенд, собственное оборудование).
