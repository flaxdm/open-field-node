# Спецификация v0.1

Рабочее название: Open Field Node / Открытый полевой узел

## Краткое описание

Открытая модульная headless‑платформа для автономной полевой связи, радионаблюдения, survival‑сценариев и аудита собственных сетей. Смартфон на Android используется как основной интерфейс. Устройство сохраняет автономность без телефона.

## Основные принципы

1. Открытые hardware и software.
2. Заменяемое compute core.
3. Модульность на базе backplane.
4. Отсутствие экрана и клавиатуры на устройстве.
5. Android‑смартфон как контроллер, а не единственный мозг.
6. Корректное сосуществование RF‑модулей.
7. Корпус под 3D‑печать.
8. Возможность расширения сообществом.

## Основные функции

- автономные полевые миссии;
- SDR‑приём/мониторинг;
- LoRa/Meshtastic;
- опциональный DMR hotspot;
- два Ethernet;
- два Wi‑Fi;
- LTE с SIM;
- offline survival‑сервисы;
- лаборатория аудита собственных сетей.

## Не‑цели для v0.1

- сертификация конечного продукта;
- финальный механический стандарт;
- финальный RF front‑end;
- полное правовое покрытие всех регионов.
