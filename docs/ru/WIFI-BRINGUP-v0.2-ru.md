# OFN Заметки по поднятию Wi-Fi v0.2

Как превратить отладочную станцию на CM5 в точку доступа управления узлом через USB-WiFi-донгл в слоте H2 (USB3 19-pin). Решение D12.

## 1. Железо

| Компонент | Статус | Примечания |
|---|---|---|
| Донгл MT7921AU (драйвер в ядре) | предпочтительно | работает из коробки на ядре ≥5.18; у CM5 ядро 6.6+, ок |
| Донгл RTL8811AU | запасной | нужен внешний драйвер `rtl8811au` (dkms); брать только если MT7921AU не найдётся |
| Антенна | обязательно | штатная «утка» 2 dBi хватает на 10–20 м канала управления |

Покупаем один донгл MT7921AU. Избегать RTL8812AU (драйверная каша) и любого Realtek без драйвера в основном ядре.

## 2. Определяем интерфейс

```bash
lsusb | grep -i -E "mediatek|ralink|realtek"
ip link                 # появился новый wlan-интерфейс
iw dev                  # покажет phy#, имя интерфейса, поддерживаемые диапазоны
```

Ожидается: `Interface wlan0` (у нашего ядра CM5 Lite беспроводного модуля нет, так что это будет wlan0).

## 3. Базовый конфиг hostapd

Сохранить как `/etc/hostapd/ofn.conf`:

```ini
interface=wlan0
driver=nl80211
ssid=OFN-0001
hw_mode=g
channel=6
ieee80211n=1
wmm_enabled=1
auth_algs=1
wpa=2
wpa_passphrase=change-me-pairing
wpa_key_mgmt=WPA-PSK
rsn_pairwise=CCMP
country_code=RU
ignore_broadcast_ssid=0
```

Замечания:
- Фиксированный канал 6 — на полевом устройстве не нужен auto-channel (предсказуемость важнее пропускной способности).
- Мощность: оставить по умолчанию; если важны помехи — `txpower` через `iw` (≤14 dBm по RF-плану).
- Суффикс SSID — идентификатор устройства из pairing; `OFN-0001` — заводской дефолт до привязки.

## 4. Статический IP + DHCP только для телефонов

`/etc/dnsmasq.d/ofn.conf`:

```ini
interface=wlan0
bind-interfaces
dhcp-range=10.0.0.10,10.0.0.50,255.255.255.0,24h
dhcp-option=3,10.0.0.1
dhcp-option=6,10.0.0.1
```

Эквивалент в `nmcli`/`netplan`: статический `10.0.0.1/24` на wlan0, без маршрута наружу (канал управления изолирован по замыслу; интернет позже придёт через Ethernet/USB-C).

Запуск:

```bash
systemctl unmask hostapd
systemctl enable --now hostapd dnsmasq
```

## 5. Чек-лист проверки

- [ ] `iw dev wlan0 info` → режим AP, канал 6
- [ ] Телефон видит `OFN-0001`, подключается по паролю
- [ ] Телефон получает IP из 10.0.0.10–50
- [ ] С CM5: `ping 10.0.0.x` (IP телефона) работает
- [ ] Интернета через точку доступа нет — так и задумано для изолированной сети управления

## 6. Известные грабли

1. **Чипы RTW88** (RTL8822CE и т.п.) могут первыми занять имя интерфейса — проверить `iw dev` и поправить interface в конфиге.
2. Если `hostapd` падает с `nl80211: could not configure driver mode`: донгл в режиме станции; выполнить `ip link set wlan0 down`, затем перезапустить hostapd.
3. Энергосбережение USB-донглов даёт скачки задержки: `iw dev wlan0 set power_save off`.
4. MT7921AU греется под нагрузкой точки доступа — нормально, но держать его подальше от RF-модулей.
5. Код страны обязателен (RU), иначе драйвер неправильно ограничивает каналы 1–11 и hostapd может упасть на 12/13.

## 7. Когда это станет настоящим сервисом

Рабочий конфиг перейдёт в `ofn-ctl-api` (точка доступа управляется софтом, SSID = `OFN-<id>`, код pairing = WPA-пароль, задаётся при первом сопряжении). До этого момента ручной конфиг выше — базовая линия P0.
